# usdjpy-tokyo-range-breakout-strategy-pine

TradingView Pine v6 strategy: USDJPY Tokyo range breakout (London session) + 5am JST short bias, with backtest period input

ドル円の**時間帯ベースの統合戦略**です。2つの戦略（A・B）を1つのストラテジーにまとめ、1時間足でバックテストできます。

実際の売買に使うインジケーターは [usdjpy-manual-trade-guide-indicator-pine](https://github.com/stangler/usdjpy-manual-trade-guide-indicator-pine) です。

- ファイル名（推奨）: `usdjpy-tokyo-range-breakout-strategy.pine`
- スクリプト名: `ドル円 統合戦略 (A:東京レンジ→ロンドン + B:5時売り)`
- 対象: USDJPY / **1時間足**
- 時刻: 日本時間（入力でタイムゾーンを変更できます）

## 戦略の内容

### A: 東京レンジ→ロンドン ブレイクアウト

1. 東京時間（9:00〜16:00）の高値・安値を、レンジとして記録します。
2. 16:00〜19:00 に、1時間足の終値がレンジ高値を上抜けたら買い、安値を下抜けたら売りでエントリーします（1時間足では 17:00 / 18:00 / 19:00 のいずれか）。**1日1回まで**、月〜金が対象です。
3. レンジ幅を R として、レンジ端を基準に決済価格を置きます。

| | 損切り | 利確 |
|---|---|---|
| 買い | 高値 − R × 0.5 | 高値 + R × 0.6 |
| 売り | 安値 + R × 0.5 | 安値 − R × 0.6 |

4. 損切り・利確にかからなければ、23時台の足が終わった時点（1時間足では**翌 0:00 の始値**）で時間決済します。

### B: 5時売り（時間帯バイアス）

- 火〜金の **5:00 の始値で売り**、**6:00 の始値で決済**します（保有1時間）。
- 損切り・利確はありません（入力で、損切りを pips で任意に追加できます。既定は 0 = なし）。

### 共通

- 同時に持つポジションは1つだけです。
- 注文数量は 10,000 通貨の固定です。

## バックテストの設定

| 項目 | 値 |
|---|---|
| 初期資金 | 200,000 円 |
| 注文数量 | 10,000 通貨（固定） |
| 証拠金 | 4%（買い・売り） |
| スリッページ | 2 ティック（片道およそ 0.2 pips） |
| 足 | 1時間足 |

## バックテスト結果

### 期間外の検証（主たる評価）

期間は 2025-01-01〜2026-05-31 です。パターンを見つけた期間（2026年6〜11月）より前のデータで、実質的に約 17 か月分です（1時間足のデータが 2025-01-01 以降から読み込まれます）。

| | 損益 | PF | 勝率 | 取引回数 | 最大ドローダウン |
|---|---|---|---|---|---|
| A 単独 | +55,050円 | 1.304 | 63.1% | 168 | 10.4% |
| B 単独 | +46,050円 | 1.561 | 54.3% | 293 | 8.7% |
| **A + B** | **+101,100円** | **1.384** | 57.5% | 461 | 9.5% |

AとBは時間帯が重ならないため、損益は2つの単独結果の合計と一致します。最大ドローダウンは、A 単独（10.4%）より小さく収まっています。

### コスト耐性（スリッページ 5 ティック）

片道約 0.5 pips（往復約 1 pips）に増やした場合です。

| | 損益 | PF | 勝率 | 取引回数 | 最大ドローダウン |
|---|---|---|---|---|---|
| A + B | +76,080円 | 1.277 | 53.8% | 461 | 10.8% |

B の1回あたりの平均利益は、コスト控除前で約 2 pips です。往復コストが約 2 pips を超えると、B の利益はなくなります。A は約 3.7 pips まで耐えられます。

### 見つけた期間の結果（参考・過大評価）

パターンを見つけた期間（2026年6〜11月、15分足）で測った数字です。**同じデータで選んで同じデータで検証しているため、実力より良く出ます。**

| | 損益 | PF | 勝率 | 取引回数 |
|---|---|---|---|---|
| A（15分足） | +15,800円 | 1.217 | 59.2% | 71 |
| B（15分足） | +35,540円 | 4.273 | 81.3% | 96 |

B の PF 4.27 は、期間外では 1.56 に縮みました。見つけた期間の数字は、これほど誇張されることがあります。

## 検証の進め方

1. 曜日×時間帯のヒートマップ（[ボラティリティ](https://github.com/stangler/weekday-hour-volatility-heatmap-indicator-pine) / [方向性](https://github.com/stangler/weekday-hour-direction-heatmap-indicator-pine)）で、2026年6〜11月のデータから候補を見つけます。
2. 候補を、**見つけた期間より前のデータ（2025-01-01〜2026-05-31）で検証**します。
3. 期間外でPFが基準（1.2〜1.3 以上）を満たしたものだけを残します。

## 検証して見送った案

いずれも、期間外または単独の検証で、優位性が確認できませんでした。

| 4時買い（火〜金、1時間保有、1時間足・期間外） | PF 1.112、294回、1回の平均約 0.5 pips |
| 金 NYブレイク（18〜21時レンジ→21〜24時、水〜金） | PF 1.045、64回 |

| 低ボラ時間帯のボリンジャーバンド逆張り | PF 1.006、175回 |
| ブレイクアウト＋EMAフィルター・ブレイク余裕・レンジ幅フィルターの同時追加 | PF 0.86 に悪化 |
| ブレイクアウトの2段階利確＋建値移動 | PF 1.038 に悪化 |

## 使い方

1. TradingView の Pine エディタで、**新規のストラテジー**を作成します。
2. `usdjpy-tokyo-range-breakout-strategy.pine` の内容を貼り付けて、保存します。
3. USDJPY の**1時間足**のチャートに追加します。
4. 入力タブで、検証期間（検証開始日・検証終了日）を設定します。
5. チャート右上の設定表で、足・検証期間・A / B の設定を確認します。

スクリプトは**1つずつ別の名前で保存**してください。

## 入力パラメータ

| 項目 | 既定値 |
|---|---|
| タイムゾーン | Asia/Tokyo |
| 検証開始日 | 2025-01-01 |
| 検証終了日 | 2026-05-31 |
| A を使う | ON |
| A レンジ開始時 / 終了時 | 9 / 16 |
| A エントリー受付終了時 | 19 |
| A 強制決済時 | 23 |
| A 損切り / 利確（レンジ幅倍） | 0.5 / 0.6 |
| B を使う | ON |
| B エントリー時 / 保有時間 | 5 / 1 |
| B 損切り（pips、0 = なし） | 0 |
| B 曜日 | 火・水・木・金 |

## 注意事項

- 検証期間は約 17 か月で、固定ロット（10,000通貨）の結果です。ロットを増やすと、損益もドローダウンも比例して大きくなります。
- 結果を見てからパラメータを調整すると、その期間が「見つけた期間」と同じ扱いになり、検証の意味が薄れます。新しい数値を試すときは、**今回の検証に使っていない新しい期間**で確認してください。
- B は1回あたりの利益が薄く、実際のスプレッドやスリッページに敏感です。夏時間（3〜11月）は、決済時刻 6:00 がロールオーバー時刻に重なります。
- 自動売買には対応していません。売買は、手動運用ガイドの通知を見て手動で行う想定です。
- 1時間足以外では、検証していません。
